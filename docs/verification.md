## 测试环境限制

本次自动化会话会把直接从 `E:\workspace\biga` 内启动的进程降为 Low Integrity。
Windows 不允许这类进程注册通知区域图标，因此直接运行工作区内的 exe 时托盘不出现；
把同一个 exe 复制到工作区外后进程为 High Integrity，托盘图标和右键菜单均正常。

低完整性进程也可能被 Windows 过滤部分后台 `WM_INPUT` 投递。把静态 exe 复制到
工作区外、以 High Integrity 启动后，已在前台为其他程序时验证：数字键可切换武器，
状态显示窗口随运行时状态立即刷新，右键隐藏/恢复主窗口也正常。工程使用标准
`WM_INPUT + RIDEV_INPUTSINK` 路径，未添加低层键盘钩子替代实现。
